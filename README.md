![Eunoia](docs/cover.png)

你好，我是 Eunoia。

期待与你相遇。

## 快速开始

```bash
npm install
cp .env.example .env       # 填 DEEPSEEK_API_KEY
npm run dev                # http://127.0.0.1:8787
```

需要 Node **>= 22.5**。数据库是一个文件，默认 `data/eunoia.sqlite`，不需要 Docker 或 Postgres。
